# MCP Calculator Agent

This project is a simple MCP agent built in Python.

It demonstrates how an AI agent can connect to external tools through an MCP server. The MCP server exposes calculator tools such as addition, subtraction, multiplication, and division.

## Tools Included

- `add_numbers(a, b)`
- `subtract_numbers(a, b)`
- `multiply_numbers(a, b)`
- `divide_numbers(a, b)`
